Controls

Tap a control to toggle its output. Run Mode alternates Auto UP and Auto DOWN for the configured duration.

Output controls are locked during an automatic sequence or ramp-down. Press Stop to ramp down; press it again to cut outputs immediately.

Automatic sequences

Ready Signal: Switch to Timer; configured delay the relay turns ON. The buzzer gives one 1-second beep when an access-point client connects (repeat connections within 10 seconds are ignored). After Run Mode completes, the Buzzer relay gives 2-second pulses until Stop is pressed. Stop ramps the outputs down in order (speed, direction, Enable, Brake) instead of cutting them at once; press Stop again to cut every output immediately.

Sequence timer settings

Choose each sequence-step duration, Buzzer pulse interval, Ready Signal delay (1–600 seconds), and Run Mode duration (1–24 hours). Settings are saved to ESP32 nonvolatile memory (NVS). The buzzer gives a 2-second pulse every selected interval after Run Mode completes; Stop silences it.

Wi-Fi configuration

Configure the ESP32 access point and optional router connection. Settings are saved in nonvolatile memory (NVS).

Optional: connect the ESP32 to a router.

Changing AP settings disconnects connected clients. Reconnect using the new network name and password. The default password is 12345678; change it for your bench. While the router connection is active the access point is forced onto the router's Wi-Fi channel, so clients may briefly drop when the router link comes up.

Modbus RTU slave register map

UART2 offers Modbus RTU slave, Passive Monitor, and Raw UART text modes. Only one is active at a time; choose in Protocol Analyzer. Passive Monitor never transmits. Use an RS-485 transceiver; connect its RO to GPIO16, DI to GPIO17, and tied DE+/RE to GPIO13. Configure your master to match the UART baud shown in Protocol Analyzer.

Holding registerMeaningAccess / values
0Sequence command / last commandRead/write: 0 stop, 1 up, 2 down, 3 run
1Sequence statusRead: 0 idle, 1 sequence, 2 run mode
2Output bitfieldRead: bits 0–6 = Brake, Enable, Up, Down, Speed 0, Speed 1, Speed 2
3Current step time remainingRead, seconds
16–28 (0x0010–0x001C)Sequence timer settingsRead/write: seconds, except Run Mode duration in hours

Supported functions: 03 read holding registers, 06 write single register, and 16 (0x10) write multiple timer registers. Timer writes are saved to NVS. Function 16 is for timers; use function 06 for commands.
